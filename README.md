Projeto de estudos focado em dominar o **TailwindCSS v4**. O repositório é um monorepo com dois ambientes independentes: um com **HTML/JS puro** usando o Tailwind CLI e outro com **React + Vite**, permitindo praticar os mesmos conceitos em contextos diferentes.

## 📚 Tópicos estudados

| Tópico | Descrição |
| --- | --- |
| ⚙️ Setup | Configuração do Tailwind com CLI e com o plugin `@tailwindcss/vite` |
| 🎨 Estilização | Utilitários de cores, tipografia e espaçamento |
| 📱 Responsividade | Design mobile-first com breakpoints |
| 🌙 Dark mode | `@custom-variant` com dark baseado em classe |
| 🧬 Seletores & estados | Seletores de filhos e state modifiers (`hover`, `focus`, `group`, etc.) |
| ✨ Animações | Plugin `tailwindcss-animate` |
| 🗜️ Build | Geração de CSS minificado para produção |

## 🧰 Stack

| Tecnologia | Descrição |
| --- | --- |
